### Rattlegram

Transceive UTF-8 text messages with up to 170 bytes over audio in about a second!

## 中文本地化

- 默认资源位于 `app/src/main/res/values/strings.xml`，保持与上游英文资源一致。
- 简体中文位于 `app/src/main/res/values-zh-rCN/strings.xml`，应用会跟随系统语言自动切换。

## Android 构建

推送代码或手动运行 `Android Build` 工作流后，Actions 会安装所需 JDK、Android SDK、NDK 和 CMake，执行 Debug/Release 构建与 lint，并上传 APK 和 lint 报告。
